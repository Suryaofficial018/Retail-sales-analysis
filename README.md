## 📌 Project Overview

This project analyzes **ZUDIO retail sales data** to uncover trends in sales performance, product performance, regional trends, revenue generation, and profitability patterns.

**Tools Used:** Python (Pandas, Matplotlib, Seaborn) · Power BI · Tableau

---

## ❗ Problem Statement

Retail businesses often struggle to identify:
- Which products generate maximum revenue
- Which regions perform poorly
- Seasonal sales trends
- Profitability across products
- Hidden patterns in customer purchasing behavior

Without proper analysis, businesses face poor inventory decisions, revenue loss, and weak regional performance. This project solves these challenges using data analytics and visualization.

---

## 🎯 Project Objectives

- Clean and preprocess raw sales data
- Analyze monthly sales and revenue trends
- Identify top and bottom-performing products
- Analyze regional sales performance
- Calculate profitability metrics
- Build interactive dashboards for decision-making
- Create business storytelling dashboards using Tableau

## 📊 Power BI Dashboard — Key Findings

### Sales Overview
- **August** has the highest monthly sales of **₹5.8M**
- **June** has the lowest monthly sales of **₹5.1M**
- **Thursday** has the highest daily sales of **₹9.4M**
- Top customer: Jonathan Brown with purchases of **₹52K**

### Product Performance
- **Kids category** has the highest sales of **₹21M** (12K+ units sold)
- **Men category** has the lowest sales of **₹20M**
- Top products: Dresses, Skirts, Pants, Sweaters, Jackets
- Bottom products: Hoodies, T-Shirts, Tops, Jeans, Shoes

### Regional Performance
- **West Bengal** has the highest revenue of **₹8.1M**
- **Karnataka** has the lowest revenue of **₹7.6M**
- Top cities: Jaha, Mysuru, Jammu, Kolkata, Bhopal
